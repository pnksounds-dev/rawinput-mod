# Raw Input

Fabric mod for Minecraft **26.3+** that restores raw mouse input after Mojang
removed the setting (SDL3 input backend).

Drop `build/libs/rawinput-1.0.0.jar` into your `mods` folder.
Config: `config/rawinput.json` (`"rawInput": true/false`, default `true`).

Full technical details, compatibility notes and build instructions:
[docs/RAWINPUT.md](docs/RAWINPUT.md)
